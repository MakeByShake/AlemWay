# План: довести сайт AlemWay до ТЗ (ERP/CRM) на 100 %

Сейчас готово ~35–40 %: клиенты и документы, ИИ-проверка, кабинет клиента, оплаты, работодатели, таблицы.
Всё ниже делаем на нашем же сайте — ничего не переносим, всё остаётся в одной админке.

## Этап 0. Решения до старта (от вас)
- Для кого система: только AlemWay или AlemWay + Baybol (тогда у каждой компании свои клиенты и цифры).
- Список сотрудников и их роли: учредители, директор, руководитель продаж и маркетинга (РОМК), менеджеры продаж, операционный отдел, таргетолог.
- Страны и услуги: только Германия и K-ETA или ещё Польша, Словакия и др. (у каждой свои этапы).
- Правила возврата: сколько стоит каждый этап работы, какая комиссия.
- Налоги: режим налогообложения и ставки (от бухгалтера).
- Нужны ли платные подключения: IP-телефония (звонки), официальный WhatsApp API (авто-сообщения).

## Этап 1. Роли и доступы — основа для всего (~1 день)
- Роли: учредитель, директор, РОМК, менеджер продаж, операционный отдел, таргетолог.
- Кто что видит: менеджер — своих клиентов; РОМК — весь отдел продаж; директор и учредители — всё, включая финансы.
- Проверка: зайти под каждой ролью и убедиться, что видно только своё.

## Этап 2. Задачи для сотрудников (~2 дня)
- Поставить задачу: описание + дедлайн, дата постановки сама.
- Кто кому ставит: учредители — всем; директор — всем, кроме учредителей; руководители — своим.
- Каждый видит только свои задачи. Кнопки «Приступить» → «Выполняется», «Завершить» → «Завершено».
- Пропущен дедлайн — сам «Просрочено», видят исполнитель и поручитель. Уведомление в Telegram.
- Проверка: поставить задачу с прошедшим дедлайном → станет «Просрочено».

## Этап 3. Воронка отдела продаж (~3–4 дня)
- 6 этапов: Новая заявка → Не дозвонился / в работе → Контакт, дожать на встречу → Встреча назначена → Встреча проведена → Закрыто, передано в операционный отдел.
- Карточка заявки: история касаний, «позвонил — итог», дата следующего контакта, встреча (дата, время, онлайн/офлайн).
- Закрытие сделки: сумма, договор, чек → клиент сам переходит в операционный отдел (уже работает).
- Контроль менеджеров: время ответа на новую заявку, сколько отработал, кто давно ничего не делает.
- Звонки: сначала вручную (менеджер отмечает); позже — авто через IP-телефонию (платно, по желанию).

## Этап 4. Операционный отдел до прилёта (~2–3 дня)
- Новые этапы: дата собеседования в посольстве; результат (одобрено / отказ).
- Отказ: апелляция по согласию клиента, консульский сбор, ожидание.
- Одобрено: билеты, дата и рейс прилёта, кто встречает, отметка «клиент встречен».
- Если будут другие страны — свои этапы для каждой.

## Этап 5. Финансы для руководства (~3–4 дня)
- Расходы: зарплаты (ФОТ), аренда, реклама, прочее — по месяцам.
- Расходы на конкретного клиента (документы, переводы, сборы) → прибыль по каждому клиенту.
- Налоги: расчёт по правилам бухгалтера.
- Отчёт о прибылях и убытках: одна страница — доход, расходы, налоги, чистая прибыль за месяц.
- Видят только директор и учредители.

## Этап 6. Возвраты (~2 дня)
- Стоимость этапов работы → при расторжении сайт сам считает: оплачено − сделанная работа − расходы − комиссия = к возврату.
- Клиент в кабинете видит затраты компании по этапам (как в ТЗ).

## Этап 7. Аналитика (~2–3 дня)
- Путь клиента от заявки до прилёта, где сейчас каждый.
- Статистика менеджеров: заявки, встречи, договоры, вылеты, конверсия по этапам.
- Загрузка: кто перегружен, кто простаивает.

## Этап 8. Портал для работодателей (~3 дня)
- Отдельный вход для работодателя (без доступа к админке).
- Кандидаты: анкета, резюме, навыки, документы (только закреплённые за ним).
- Прилёты: список, даты и рейсы, кого встречать.

## Этап 9. Маркетинг (~2–3 дня)
- Загрузка заявок из Excel / Google Таблиц от таргетолога (без дублей по телефону).
- План заявок на месяц, задачи таргетологу (через этап 2).
- Бюджеты и креативы рекламы, стоимость заявки.

## Что потребуется по сервисам
- Хостинг Vercel: для коммерческого сайта нужен тариф Pro (~20 $/мес) — сейчас бесплатный, на нём логи хранятся всего час.
- База Sanity: пока хватает бесплатного; при росте — платный тариф.
- ИИ (Anthropic): ~30 $/мес лимит сейчас.
- По желанию: IP-телефония (тариф оператора), WhatsApp Business API (оплата за сообщения).

## Итого
~25–30 рабочих дней по этапам 1–9. Каждый этап: делаем → проверяем на сайте → выкладываем → отчёт.
