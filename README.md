# AlemWay Visa — сайт

Сайт визового агентства AlemWay Visa (Алматы). Next.js 16 + Tailwind CSS 4 + Sanity (админка) + Vercel.
Два языка: русский `/ru/...` и казахский `/kk/...`.

- Сайт: главная, все услуги, страница каждой услуги, «О нас», «Контакты», политика конфиденциальности.
- Админка: `/studio`. Там сотрудники меняют услуги, цены, тексты и фото, а также смотрят заявки.
- Заявки с формы сохраняются в админку и приходят в Telegram.

> Пока Sanity не подключена, сайт показывает стартовый контент из `src/content/seed.ts`.
> Поэтому после первого деплоя на Vercel сайт сразу работает с тремя услугами.

## Запустить на своём компьютере

```bash
npm install
cp .env.example .env.local   # заполнить ключи (см. ниже)
npm run dev                  # открыть http://localhost:3000
```

Проверить, что всё собирается: `npm run build`.

## Подключить Sanity (админку) — один раз

1. Зайдите на https://www.sanity.io/manage и войдите (можно через Google).
2. **Create new project** → назовите `AlemWay`. Dataset: `production`, Public.
3. Скопируйте **Project ID** (8 символов, вроде `ab12cd34`).
4. В проекте: **API → CORS origins → Add CORS origin**. Добавьте:
   - `http://localhost:3000` (галочка *Allow credentials*);
   - адрес сайта на Vercel, например `https://alemway.vercel.app` (галочка *Allow credentials*);
   - позже `https://alemway.kz`.
5. **API → Tokens → Add API token**: имя `website`, права **Editor**. Скопируйте токен (он показывается один раз).
6. Впишите в `.env.local` и в Vercel (Settings → Environment Variables):
   ```
   NEXT_PUBLIC_SANITY_PROJECT_ID=ваш_id
   NEXT_PUBLIC_SANITY_DATASET=production
   SANITY_API_WRITE_TOKEN=ваш_токен
   SANITY_REVALIDATE_SECRET=любая_длинная_случайная_строка
   ```
7. Залейте стартовый контент: `npm run seed`. Повторный запуск обновляет документы, а не дублирует их.
8. В Vercel нажмите **Redeploy**. Админка откроется по адресу `/studio`.

### Чтобы изменения из админки сразу появлялись на сайте (webhook)

Sanity → проект → **API → Webhooks → Create webhook**:
- URL: `https://ВАШ-САЙТ/api/revalidate`
- Dataset: `production`, Trigger on: Create, Update, Delete
- HTTP method: `POST`
- Secret: то же значение, что `SANITY_REVALIDATE_SECRET`

Без вебхука сайт тоже обновится сам, но в течение часа.

## Подключить Telegram (уведомления о заявках)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите токен вида `123456:ABC...`.
2. Создайте группу для команды и добавьте туда бота (или просто напишите боту `/start`, если уведомления нужны лично вам).
3. Напишите в группу любое сообщение, затем откройте в браузере
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   и найдите `"chat":{"id": ...}`. У группы id начинается с минуса, например `-1001234567890`.
4. Впишите в `.env.local` и в Vercel:
   ```
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```

Если не подключены ни Sanity, ни Telegram, форма честно скажет клиенту «не получилось отправить» и предложит WhatsApp. Заявка не потеряется молча.

## Как пользоваться админкой

### Поменять цену
Админка → **Услуги** → нужная услуга → поле **Цена, ₸** → **Publish**.
Если цену называет менеджер, включите **Цена по запросу**.

### Добавить новую страну / услугу
1. **Услуги → +** (создать).
2. Заполните: название (RU и KZ), **Адрес страницы** (нажмите *Generate* или впишите латиницей, например `visa-japan`), категорию, флаг, короткое описание, цену или «по запросу», срок, текст для WhatsApp.
3. Вкладка **Страница** → **Блоки страницы** → *Add item*. Доступные блоки: текст, что входит, документы, шаги, тарифы, вопросы-ответы, фото + текст, галерея, призыв, предупреждение, цифры. Блоки можно перетаскивать.
4. **Publish**. Услуга сама появится в меню, на главной, в форме заявки и в sitemap.

Чтобы спрятать услугу, не удаляя её, выключите **Показывать на сайте**.

### Смотреть заявки
Админка → **Заявки**. Внутри списки «Все», «Новая», «В работе», «Оплачено», «Закрыто».
Откройте заявку, поменяйте **Статус**, при необходимости напишите **Заметку менеджера** → **Publish**.
В Telegram у каждой заявки есть ссылка «Открыть в админке» и кнопка «Написать в WhatsApp».

### Тексты главной, контакты, цифры доверия
Админка → **Настройки сайта**.

### Казахские тексты
Все `KZ` поля — черновой перевод. Их нужно проверить носителем языка (подсказка есть у каждого поля).

## Аналитика

- **Vercel Web Analytics** включается в Vercel: проект → **Analytics → Enable**. Cookie не использует.
- **Яндекс Метрика** (по желанию): создайте счётчик на metrika.yandex.ru и впишите номер в `NEXT_PUBLIC_YM_ID`. Тогда внизу сайта появится короткое уведомление про cookie.
- Цели: `lead_submit` (отправлена заявка), `whatsapp_click` (нажали WhatsApp), `service_open` (открыли услугу). В Метрике создайте цели типа «JavaScript-событие» с этими названиями.
- UTM-метки рекламных ссылок сохраняются в заявку.

## Деплой на Vercel

1. Vercel → **Add New → Project** → выберите репозиторий `MakeByShake/AlemWay` → **Deploy** (настройки по умолчанию).
2. **Settings → Environment Variables**: добавьте всё из `.env.example` (`NEXT_PUBLIC_SITE_URL` = адрес сайта).
3. **Deployments → Redeploy**, чтобы переменные применились.
4. Когда купите домен: **Settings → Domains → Add** `alemway.kz`, поменяйте `NEXT_PUBLIC_SITE_URL`, добавьте домен в CORS Sanity и в webhook.

## Где что лежит (для разработчика)

| Путь | Что это |
|---|---|
| `src/app/[locale]/` | Страницы сайта |
| `src/app/studio/` | Админка Sanity |
| `src/app/api/lead` | Приём заявок → Sanity + Telegram |
| `src/app/api/revalidate` | Webhook Sanity → обновление страниц |
| `src/sanity/schemaTypes/` | Схемы админки (услуги, блоки, заявки…) |
| `src/content/seed.ts` | Стартовый контент (`npm run seed`) |
| `src/components/blocks/` | Отрисовка блоков конструктора |
| `messages/ru.json`, `kk.json` | Тексты интерфейса |
| `public/brand/` | Логотипы |
