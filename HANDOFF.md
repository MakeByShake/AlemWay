## 1. Что сделано

**Админка и данные**
- Админка Sanity встроена в сайт: `/studio` (Next.js + `sanity.config.ts`). Услуги, категории, FAQ, отзывы, настройки сайта, заявки, личные кабинеты.
- Стартовый контент — `src/content/seed.ts`, заливка `npm run seed` (повторный запуск обновляет, не дублирует).
- Заявки с формы сохраняются в Sanity и отправляются в Telegram (`src/app/api/lead`).

**Безопасность (OWASP)** — коммит `4f98287` и далее
- Заявки (`leads.<uuid>`) и кабинеты (`cabinets.<uuid>`) создаются сервером с id через точку: в публичном dataset такие документы **не читаются без токена**. В Studio запрещено создавать/дублировать лиды и кабинеты (копия получила бы публичный id).
- `/api/lead`: только same-origin, только JSON, лимит 8 КБ, проверка полей, honeypot, простой rate limit (в памяти инстанса).
- Заголовки (`next.config.ts`): CSP для сайта, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, COOP; `/studio` — `noindex`; без `X-Powered-By`.
- Файлы клиентов — только в **приватном** Vercel Blob, отдаются через API владельцу кабинета (httpOnly-cookie) или менеджеру; тип файла проверяется по содержимому (PDF/JPG/PNG), лимит 4 МБ.
- Менеджерские API (`/api/admin/*`) проверяют, что Bearer-токен принадлежит участнику проекта Sanity (`src/lib/admin-auth.ts`). Общего пароля нет. Studio работает в режиме `auth.loginMethod: "token"`, чтобы передавать этот токен.
- Ключ входа клиента: 32 случайных байта, в базе только SHA-256; ссылка `/c/<key>` ставит httpOnly-cookie и редиректит (ключ не остаётся в адресной строке).

**Цены скрыты** — коммит `fb16c91`
- `src/lib/prices.ts`: `SHOW_PRICES = false`. Скрыты цены в карточках, на странице услуги, блоки тарифов, `offers` в JSON-LD; суммы «₸» вырезаются из текстов админки при показе (данные не меняются). Вернуть — `true`.

**Главная** — коммит `516e88c`
- Первый экран ровно в высоту экрана; на главной шапка прозрачная поверх фото и белеет при приближении мыши к верху, прокрутке, открытом меню, фокусе.
- Вместо одной карточки «Популярное» — карусель всех услуг (`src/components/HeroServices.tsx`: scroll-snap, свайп, стрелки, точки, ← →).

**Контакты** — коммит `5e13756`: +7 777 588 29 49, alemway.kz@gmail.com, @alemway_visa (в админке «Настройки сайта» и запасные значения в коде).

**Личный кабинет Ferienjob** — коммиты `ad16158`, `2f96c14`
- Менеджер создаёт кабинет → ссылка клиенту. Клиент: анкета + загранпаспорт + справка из вуза.
- Сайт сам заполняет официальную декларацию **ZAV** (`src/assets/zav-declaration-blank.pdf` — одностраничный бланк BA 08/2025, очищенный от чужих данных; `src/lib/cabinet/declaration.ts`, pdf-lib). Значения по-немецки (`Kasachstan`, радио `ja/nein`), поле 20 «Date» = день создания (Asia/Almaty).

## 2. Что не доделано / в планах / известные ограничения

- **Данные старого проекта Sanity `btu84bxr`** (кабинеты, заявки) в новый проект переносятся владельцем. Файлы старых кабинетов выгружены отдельно в архив `alemway-cabinet-files.zip` (не в git — там паспорта). В старых документах `files.<kind>.path` указывает на **старый** Blob — в новом проекте эти пути работать не будут, файлы нужно перезалить (в кабинете: «Файлы» → «Заменить»).
- Правило K-ETA «не больше 60 дней за 180» не проверяется (только 30 дней подряд).
- Статус K-ETA «подано» ставится вручную; связи с k-eta.go.kr нет.
- Удаление кабинета в Studio **не удаляет** его файлы из Blob — чистить вручную в Vercel → Storage.
- Rate limit формы заявок — в памяти одного инстанса (на Vercel не глобальный).
- Загрузка файлов: максимум 4 МБ (лимит тела запроса Vercel). Фото с телефона уменьшаются в браузере; HEIC конвертируется только там, где браузер умеет его открыть.
- Декларация ZAV печатается шрифтом Helvetica (в образце Roboto был не встроен).
- Казахские тексты — черновой перевод, проверить носителем.
- Политика конфиденциальности — шаблон; нужен юрист и реквизиты.
- Временные фото (часть с baybolgc.kz, часть с Wikimedia), нет отзывов, `TODO` в вопросах Ferienjob, нет контента по визе в Австралию.
- Webhook Sanity → `/api/revalidate` не настраивался: без него изменения из админки видны в течение часа (ISR `revalidate = 3600`) или после пересборки.
- `npm audit`: уязвимости только в инструментах Sanity CLI (js-yaml, smol-toml, undici), не в коде сайта; исправление — мажорное обновление Sanity.
- CSP содержит `'unsafe-inline'` для скриптов (страницы статические, nonce невозможен).
- Менеджерам после перехода Studio на `loginMethod: "token"` нужно один раз войти заново.

## 4. Переменные окружения

| Переменная | Нужна | Для чего |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | да | Публичный адрес сайта без `/` на конце: канонические ссылки, sitemap, ссылки «Открыть в админке», ссылки входа в кабинет. В Vercel — тип **Config** (не Secret: `NEXT_PUBLIC_*` нельзя делать Secret). |
| `NEXT_PUBLIC_SANITY_PROJECT_ID` | да | ID проекта Sanity. Без него сайт работает на стартовом контенте из кода, админка не подключена. Config. |
| `NEXT_PUBLIC_SANITY_DATASET` | да | `production`. Config. |
| `NEXT_PUBLIC_SANITY_API_VERSION` | нет | Версия API Sanity, по умолчанию `2025-10-01`. |
| `SANITY_API_WRITE_TOKEN` | да | Серверный токен Editor: запись заявок и кабинетов, чтение приватных документов, `npm run seed`. Secret. |
| `SANITY_REVALIDATE_SECRET` | для вебхука | Секрет подписи вебхука Sanity → `/api/revalidate`. Secret. |
| `TELEGRAM_BOT_TOKEN` | да | Бот для уведомлений о заявках и кабинетах. Secret. |
| `TELEGRAM_CHAT_ID` | да | ID канала/группы для уведомлений. |
| `BLOB_READ_WRITE_TOKEN` | да (прод) | Доступ к **приватному** Vercel Blob для файлов кабинетов. Появляется сам при подключении store к проекту (отметить read-write token). Без него в production загрузка файлов падает. |
| `BLOB_STORE_ID` | нет | Добавляется Vercel при подключении store (вариант доступа через OIDC). |
| `NEXT_PUBLIC_YM_ID` | нет | Номер счётчика Яндекс Метрики; пусто — не подключается. |
| `VERCEL_PROJECT_PRODUCTION_URL` | авто | Ставит Vercel; запасной адрес сайта, если нет `NEXT_PUBLIC_SITE_URL`. |

Локально — файл `.env.local` (в `.gitignore`). Без Blob-токена файлы локально пишутся в `.data/blob` (тоже в `.gitignore`).

## 5. Как проверить кабинет руками (от начала до конца)

Подготовка: в Vercel заданы все переменные из таблицы, Blob (Private) подключён, адрес сайта есть в CORS Sanity, вы участник проекта Sanity.

**Ferienjob**
1. `https://<сайт>/studio` → войти → «Личные кабинеты» → «Новый кабинет» → услуга «Летняя работа в Германии (Ferienjob)» → имя, телефон → «Создать кабинет и ссылку». Скопировать ссылку.
2. Открыть ссылку в другом браузере/инкогнито → должен открыться «Здравствуйте, …», 4 шага.
3. Ввести кириллицу в «Имя» → «Отправить» → поле подсвечено «Только латиница…». Исправить, заполнить все поля латиницей, загрузить 2 файла (PDF/JPG/PNG до 4 МБ) → «Отправить и получить декларацию».
4. Ожидается: шаг 2, блок «Декларация готова», дата = сегодня; «Скачать декларацию (PDF)» — одностраничный бланк BA с вашими данными. В Telegram: «📝 Анкета Ferienjob заполнена».
5. Загрузить любой PDF как подписанную декларацию → шаг 3 «Ожидание ZAV»; в Telegram «✅ Подписанная декларация загружена».
6. В Studio открыть кабинет → «Файлы»: все файлы скачиваются. «Загрузить ZAV» → статус «ZAV получен — контракт есть», кнопка «Сообщить клиенту в WhatsApp». Вкладка «ZAV и контракт» → работодатель, даты, сообщение → Publish.
7. У клиента (обновить страницу): «ZAV получен — контракт есть 🎉», данные работы, «Скачать ZAV».
8. Проверка исправления: вкладка «Анкета» → поменять поле → Publish → меню «…» → «Пересоздать декларацию» → у клиента новая декларация с сегодняшней датой.

**K-ETA**
1. «Новый кабинет» → услуга «K-ETA в Южную Корею» → ссылка → открыть.
2. Даты въезда/выезда с разницей > 30 дней → ошибка «Без визы можно не больше 30 дней подряд». Паспорт «действует до» раньше выезда → ошибка паспорта. Дата рождения, при которой на въезде ≤17 лет → жёлтая подсказка.
3. Корректные данные + скан паспорта + фото → «Отправить данные» → «Данные получены — готовим заявку»; в Telegram «🇰🇷 Анкета K-ETA заполнена».
4. Studio: статус «K-ETA: подано» → Publish → у клиента «Заявка подана — ждём решения».
5. «Файлы» → «Загрузить одобренный K-ETA» → статус «K-ETA: одобрено»; вкладка «K-ETA» → «действует до» → Publish → у клиента «K-ETA одобрен 🎉», срок, «Скачать одобрение», правила.

**Безопасность (быстро)**
- `GET https://<projectId>.api.sanity.io/v2025-10-01/data/query/production?query=count(*[_type in ["lead","cabinet"]])` без токена → `0`.
- `POST /api/admin/cabinet` без заголовка Authorization → `401`.
- `GET /api/cabinet/file/passport` без cookie кабинета → `401`.
- `/c/abc` → редирект на `/ru/cabinet?invalid=1` («Ссылка не работает»).
